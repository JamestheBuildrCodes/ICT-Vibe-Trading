# Glossary

- **C1:** CRT range candle.
- **C2:** CRT manipulation/sweep candle.
- **C3:** CRT execution window.
- **FVG:** Fair Value Gap, represented by an imbalance zone according to the model implementation.
- **Liquidity:** A price area associated with resting orders or obvious highs/lows; exact operational definitions belong to the relevant model.
- **Displacement:** Strong directional price movement; it is a concept and is not automatically a mandatory CRT confirmation.
- **Order Block:** A model-specific price structure used for execution or context.
- **Breaker:** A model-specific structure derived from failed/invalidated order-block behavior.
- **Turtle Soup:** A liquidity-sweep/reversal concept; it should not be assumed identical to CRT without an explicit model specification.
